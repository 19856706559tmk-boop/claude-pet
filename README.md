# Claude 桌面宠物

一只像素风的小 Claude 螃蟹。它住在 Claude 桌面端的窗口里，会随机走动、发呆、做各种小动作。你用 Claude 干活时它会跟着做对应的动作，也能随时查看 5 小时额度和 7 天（周）额度。

仅支持 Windows（用到了 tkinter 和一些 Win32 API）。需要 [Python 3](https://www.python.org/downloads/)（只用自带的标准库，不用装任何依赖）和 Claude 桌面端。English README: [README.en.md](README.en.md)。

## 它会做什么

它说的话、头顶的标签全部是中文。

**平时（随机）**：走来走去，偶尔走到鼠标附近；还会坐下、东张西望、挥手、蹦一下、跳舞、伸懒腰、打哈欠。眼睛会跟着鼠标转，也会眨眼。另外有几个花样动作：

| 动作 | 样子 |
|---|---|
| 转圈 | 眼睛滑到一边、转到背面、再从另一边转回来，转完晕一下 |
| 抛球 | 抛接三个彩色小球，最后一把全接住 |
| 追蝴蝶 | 眼睛跟着蝴蝶转，扑两下没扑到，最后蝴蝶自己停到它头顶 |
| 喝咖啡 | 捧着杯子喝一口再舒一口气；额度快用完时会频繁喝"续命咖啡" |
| 墨镜太空步 | 墨镜从头顶落下来戴上，倒着滑一段 |

超过 10 分钟没动静就会趴下睡觉（头顶冒"呼""噜"）；晚上 10 点到早上 7 点睡觉时会戴睡帽。出场打招呼的话会跟着时间变（早上好、晚上好、夜深啦…）。

**跟着 Claude 的工作**：

| Claude 在做什么 | 宠物的动作 |
|---|---|
| 你刚发出消息，Claude 在思考 | 头顶"思考中…"气泡，抬眼望天，一会儿挠头、一会儿脚尖点地，偶尔冒问号、亮灯泡 |
| 运行命令（Bash / PowerShell） | 敲一台黑底绿字的小终端 |
| 读文件（Read） | 举着一页文件一行一行读，读完换下一页 |
| 搜索（Grep / Glob / 找工具等） | 举着放大镜来回扫，扫到东西眼睛一亮 |
| 上网（WebSearch / WebFetch / 浏览器工具） | 踩着冲浪板在浪上起伏（上网冲浪） |
| 写代码（Edit / Write / MultiEdit / NotebookEdit） | 侧过身，握着铅笔在地上一行一行地写，头顶飘出 `{ }`、`</>` 之类的符号 |
| 列计划（任务清单类工具） | 举着写字板一项一项打勾 |
| 使用技能（Skill） | 戴上巫师帽挥魔杖，杖尖冒星星 |
| 派出子代理（Agent / Workflow） | 召唤出两只小分身 |
| **Claude 在等你回答**（提问、等你确认计划） | 旁边插一块问号牌，朝你挥手，隔一会儿蹦一下，直到你回答为止 |
| 其他工具（MCP 等） | 抡锤子敲齿轮，敲一下转一格 |
| 回复完成 | 跳起来欢呼"搞定！" |
| 被打断或出错 | 慌张流汗"诶？" |

工作时头顶会用中文显示正在做的事，比如"运行命令""改代码""上网搜索"。

**跟着额度**：

- 每用掉一点额度，天上会掉下一块饼干，它接住后三口吃掉，然后显示用掉了多少，比如 `5小时 -0.7%`。
- 额度用到 50%、80%、90% 时会举起小红旗使劲摇。
- 用到 80% 以上会变累：走得慢、偶尔流汗、更爱坐着、靠咖啡续命。
- 用光后趴着睡觉，点它会告诉你多久后恢复。
- 额度重置时，头顶的电池一格一格充满，然后跳起来欢呼"额度恢复啦！"。

## 怎么和它互动

- **左键单击**：打开或关闭额度面板。面板显示 5 小时额度和 7 天额度各剩多少、多久后重置，以及数据是多久前更新的。
- **左键拖动**：把它拎起来。松手时如果在 Claude 窗口里，它会落回窗口底部；拖到窗口外面，它就在屏幕底部（任务栏上方）自由游荡。
- **双击**：摸摸头，冒爱心。
- **右键**：菜单里有查看额度、回到 Claude 窗口、哄它睡觉 / 叫醒、跳支舞、退出宠物。

## 它什么时候出现、什么时候消失

- Claude 桌面端一打开，后台的监视器（见下面"随 Claude 启动"）就会把它启动起来，不用等你进入对话。
- 另外，每次打开一个对话时，插件也会检查一遍，没在运行就启动。已经在运行的话，不会再多开一只。
- 用右键"退出宠物"后，它在这次 Claude 运行期间不会被监视器再拉回来；下次打开 Claude，或者新开一个对话时才会回来。
- 在家（Claude 窗口里）时，它一直贴在 Claude 窗口上面一层：其他窗口盖住 Claude 时它也会被盖住，Claude 最小化时它跟着藏起来。
- 被拖出去时，它在所有窗口最上层。
- Claude 桌面端完全退出后，它会在几秒内自己退出。

## 额度说明

Claude 订阅没有"日额度"，最短的是 **5 小时窗口**，另外还有 **7 天（周）窗口**，面板里显示的就是这两个。这些数据来自 Claude 每次回复附带的额度信息，所以刚打开时可能显示"还没有额度数据"，发一条消息、等 Claude 回复后就有了。

数字什么时候更新：

- Claude 干活时，每次工具调用和每次回复结束都会读一次最新额度，数字有变化就更新，不用等整个回合结束。
- 到了重置时间，面板直接显示为已恢复，不用等下一次回复。
- 同时开着多个对话时，以最近收到回复的那个对话为准；刚打开的对话不会用它手里的旧数字盖掉新数字。
- 面板右上角的"多久前更新"是数据的真实时间。额度数据只能跟着 Claude 桌面端 Code 对话里的回复一起到达，所以在网页版、手机或别的设备上用掉的额度，要等这里下一次收到回复才会反映出来。

## 文件说明

| 文件 | 作用 |
|---|---|
| `pet.pyw` | 宠物本体，也是监视器（加 `--watch` 运行）。只用 Python 自带的 tkinter 和 ctypes，不需要安装任何依赖 |
| `config.example.json` | 配置模板，复制为 `config.json` 后修改（`config.json` 是你本机的配置，不会被上传）：`pythonw` 填 `pythonw.exe` 的路径，插件用它来启动宠物，路径请用正斜杠（`C:/Python/pythonw.exe`），单个反斜杠会让整个文件解析失败、宠物无法自动启动；`pet_size`、`panel_size`：宠物和额度面板（含右键菜单）的大小倍数（默认 1.0，比如改成 0.8 更小、1.3 更大），改完后重启宠物生效 |
| `mod/` | Claude Code 插件 `desk-pet-bridge`：把额度和 Claude 的活动写进下面两个文件，并在会话开始时启动宠物 |
| `.claude-plugin/marketplace.json` | 让 Claude Code 可以直接从这个文件夹安装插件 |
| `quota.json`、`activity.json` | 运行时自动生成的数据文件（已在 `.gitignore` 里，不会被上传），可以随时删除 |
| `bridge.json` | 插件每次在会话里加载时写的心跳，用来确认插件有没有在运行 |
| `launch-error.json` | 插件自动启动宠物失败时写下的原因（正常情况下不存在） |
| `pet.log` | 出错时写的日志 |

## 安装（让插件在每个对话里运行）

1. 克隆本仓库（或者下载 ZIP 解压）：

   ```bash
   git clone https://github.com/19856706559tmk-boop/claude-pet.git
   ```

2. 把 `config.example.json` 复制一份，改名为 `config.json`，其中 `pythonw` 填你电脑上 `pythonw.exe` 的实际路径。路径请用正斜杠（比如 `C:/Users/me/AppData/Local/Programs/Python/Python313/pythonw.exe`）；不知道路径的话，在 PowerShell 里运行 `where.exe pythonw` 可以查到。

3. 在 `C:\Users\<你>\.claude\settings.json` 的 `env` 里加上插件文件夹（下面路径换成你实际克隆的位置）：

   ```json
   "env": {
     "CLAUDE_CODE_PLUGIN_DIRS": "D:\\apps\\claude-pet\\mod"
   }
   ```

4. 完全退出 Claude 再重新打开。

为什么不用 `claude plugin install`：用安装方式装上的插件，它的钩子模块受 Claude Code 的服务器端灰度开关 `tengu_plugin_hooks_modules` 控制。这个开关没打开时，插件会显示"已启用"，但钩子不会运行。`CLAUDE_CODE_PLUGIN_DIRS` 是官方给桌面端会话准备的加载插件文件夹的方式。`.claude-plugin/marketplace.json` 先保留着，等开关开放后也可以改回安装方式。

## 随 Claude 启动（监视器）

插件只有在打开对话时才运行，所以单靠插件，宠物要等你进入第一个对话才出现。监视器补上这一段：它随 Windows 登录在后台启动，每 2 秒看一眼 Claude 桌面端有没有打开，一打开就把宠物拉起来。它没有窗口，只做这一件事。

登记（只需要做一次，登记在当前用户的登录启动项里，名字是 `ClaudeDeskPetWatcher`；`<项目路径>` 换成你克隆的位置）：

```bash
"<python.exe 的路径>" "<项目路径>\pet.pyw" --install-autostart
```

登记后从下次登录 Windows 起生效。想马上生效，可以手动开一次监视器：

```bash
"<pythonw.exe 的路径>" "<项目路径>\pet.pyw" --watch
```

取消登记：

```bash
"<python.exe 的路径>" "<项目路径>\pet.pyw" --uninstall-autostart
```

也可以在任务管理器的"启动应用"里把它关掉。如果移动了这个文件夹或换了 Python，需要重新登记一次。

## 手动启动

```bash
"<pythonw.exe 的路径>" "<项目路径>\pet.pyw"
```

调试参数：`--keep`（Claude 没开也不退出）、`--demo`（依次演示所有动作）、`--show-panel`（启动后直接打开额度面板）。

## 卸载

1. 右键菜单里选"退出宠物"。
2. 运行上面的"取消登记"命令，然后在任务管理器里结束带 `--watch` 的 `pythonw.exe`（或者注销一次）。
3. 从 `~/.claude/settings.json` 的 `env` 里删掉 `CLAUDE_CODE_PLUGIN_DIRS` 那一行。
4. 删除这个文件夹。
